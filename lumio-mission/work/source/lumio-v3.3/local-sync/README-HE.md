# Lumio × סנכרון מקומי — הוראות בעברית

כלי סנכרון **מקומיים**: הם רצים **במחשב שלך**, מתחברים למערכת עם **החשבון שלך**,
וסופגים את הנתונים (משימות/ציונים) ללומיו עם **מפתח הסנכרון** שלך.

## למה מקומי?
- משו״ב ואופק **אין להם API רשמי פתוח** — אין אפשרות לסנכרן מהשרת בלי להחזיק
  סיסמאות שלכם (ולומיו לעולם לא מחזיקה סיסמאות).
- הפתרון: הסקריפט רץ אצלכם. **הסיסמה נכנסת למחשב שלכם בלבד** — היא לא נשמרת
  בלומיו, לא נשלחת ללומיו, ולא נישארת בקבצים.
- "אוטומטי" = אחרי ריצה ראשונה, אתה מריץ עם `--loop` או שותר את הסקריפט
  כמשימה מתוכננת — ומאז הוא מסנכרן לבד.

## ההתקנה (פעם אחת)
```
pip install pymashov        # רק למשו״ב
```
(לקבצי Python עצמם אין תלויות — סטנדרטלייב בלבד.)

## שלב 1 — מפתח סנכרון מלומיו
1. התחבר ללומיו: <https://origit892-stack.github.io/lumio-site/>
2. בכרטיס המערכת הרלוונטי (משו״ב / אופק / פטל) לחץ **"מפתח סנכרון"** → **"העתק"**.
   המפתח הוא קוד כניסה למערכת שלך בלבד — אפשר לסובב/למחוק אותו בכל עת.

## שלב 2 — משו״ב
```
python mashov_sync.py --username <ת.ז> --semel <סמל מוסד> --student-id <מספר תלמיד> --sync-key <מפתח>
```
- ראשונה: כדאי עם `--dry-run` (הצגת הנתונים ללא שליחה) — ודא שהמשימות/ציונים נראים.
- עם `--save-key` המפתח יישמר ב־`~/.lumio/config.json` (הרשאות 600) ולפי ריצות
  הבאות מספיק: `python mashov_sync.py --username ... --semel ... --student-id ...`
- **אוטומטי**: `python mashov_sync.py ... --loop 4` (סנכרון כל 4 שעות) + שמירה
  כמשימה מתוכננת (הוראות למטה).
- אם לא יודע את מספר התלמיד: נסה `--discover`.

## שלב 3 — Moodle (למשל פטל)
```
python moodle_sync.py --base <כתובת Mood> --username <משתמש> --password <סיסמה> --sync-key <מפתח>
```
- אופצייה ללא סיסמה: אם אתה כבר מחובר בדפדפן, העתק את ה־cookie (`--cookie`)
  וה־sesskey (`--sesskey`) וריץ בלי סיסמה בכלל.
- `--dry-run` מציג את הפריטים שנלקטו — בדיקה חובה לריצה ראשונה (דפי Moodle
  משתנים בין מוסדות; אם הניתוח מפספס, שלח את הפלט ויותאם).
- המסלול המוכח תמיד: **קישור ICS אישי** של היומן — מתחבר בלומיו ישירות
  כפיד, בלי סקריפט.

## שלב 4 — אופק
אופק מתחבר ב**תוסף דפדפן** (תיקיית `ofek-extension`) — ראה את ה־README שם.
התוסף סופג את המשימות מהדף שלך (עם הסשן הקיים בדפדפן) ושולח בלחיצת כפתור.

## משימה מתוכננת (סנכרון אוטומטי מלא)
**Windows** (Task Scheduler):
1. `win+r` → `taskschd.msc` → משימה חדשה.
2. פעולה: `python C:\path\to\mashov_sync.py --username ... --semel ... --student-id ... --loop 4`
3. להפעלה: "התחל משימה רק כאשר המחשב בשימוש" כרצונך.

**macOS** (launchd או crontab):
```
crontab -e
0 8 * * 1-5  python3 /Users/<you>/lumio/local-sync/mashov_sync.py --username ... --semel ... --student-id ...
```

## מה קורה עם הנתונים?
- משימות וציונים נשמרים **רק במערכת שלך** בלומיו (RLS — אף אחד אחר לא רואה).
- המערכת מסומנת כ**"סנכרון מקומי"** — לא "API רשמי" — כי זה בדיוק מה שהיא.
- ניתוק המערכת בלומיו (+"מחיקת נתונים") מנתק גם את המפתח — הסקריפט יפסיק לעבוד.

## מה עדיין לא אוטומטי?
- **שחף**: אוטומטי מלא מהשרת (כשהמחשב כבוי) — דרך הפיד הציבורי
  katzirb.shahaf.site + pg_cron (מצד לומיו).
- **Google Classroom**: אוטומטי מלא מהשרת — דרך Apps Script בחשבון שלך
  (תיקיית `apps-script`).
- משו״ב/אופק/פטל: אוטומטי **מהמחשב שלך** (כמתוכנן) — כי אין להם API פתוח
  ואסור ללומיו להחזיק את הסיסמאות שלכם.

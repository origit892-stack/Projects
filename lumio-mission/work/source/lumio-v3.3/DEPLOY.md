# לומיו 3.0 — הוראות התקנה ופרסום

## הפעלה מהירה על Mac

1. חלץ את ה־ZIP ופתח Terminal בתוך `lumio-v3`.
2. הרץ `npm run dev`. אין צורך ב־npm install; לפרויקט זה אין תלויות npm.
3. פתח `http://localhost:5173`. אם הפורט תפוס: `PORT=5174 npm run dev` ואז `http://localhost:5174`.
4. אם לא נוצרו טבלאות בפרויקט Supabase שלך, הרץ **פעם אחת** את `database.sql` ב־SQL Editor. אין צורך להשאיר את Supabase פתוח.
5. הירשם ללומיו עם אימייל וסיסמה. תיתכן בקשת אישור אימייל.

## הגדרות ענן — פרסום חינמי ב־Cloudflare Pages

העלה את התיקייה `lumio-v3` כ־Direct Upload. האתר מורכב מקבצים סטטיים בלבד ואינו זקוק ל־`server.mjs` בפרסום. כדי להבטיח שהנתיבים המוחלטים עובדים, העלה את **תוכן** התיקייה, ולא תיקיית אב שמקיפה אותה. המפתח ב־`config.mjs` הוא Publishable בלבד; **אין** להוסיף service_role או sb_secret.

## ההתחברות והנתונים

הכניסה ללומיו היא דרך Supabase Auth. RLS בקובץ SQL מבודד רשומות לפי המשתמש. אין לשמור פרטי הזדהות משרד החינוך בלומיו.

## חיבורי מערכות

- Google Classroom: קריאה דרך API רשמי דורשת OAuth Client ID. כאשר הוא אינו מוגדר, הגרסה אינה מציגה כפתור חיבור שמעמיד פנים שהוא עובד. אפשר לייבא משימות ידנית.
- משו״ב, אופק ופטל: לחץ על קישור המקור, התחבר באתר הרשמי, העתק שורות של משימות והדבק במסך חיבורים; במחשב ניתן גם להשתמש בתוסף שיצור קובץ JSON. אין סנכרון רציף בלי ממשק נתונים מורשה.
- שחף: בחירת בית ספר ושכבה בחשבון; נתונים חיים מחייבים כתובת פרסום מורשית של בית הספר. אפשר להוסיף משימות ידנית.
- הודעות WhatsApp אינן משולבות, לבקשת המשתמש.

## בדיקות

הרץ `npm test`. כל הנתונים המועתקים עוברים נרמול ובדיקת מקור לפני שמירה. לא בוצע ניסוי חי עם חשבונות תלמידים במערכות המקור.

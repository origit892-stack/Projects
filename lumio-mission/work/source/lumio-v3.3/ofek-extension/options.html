איך משתמשים:
1. שמור את מפתח הסנכרון (יוצר בלומיו: כרטיס אופק → מפתח סנכרון).
2. התחבר לאופק כרגיל.
3. פתח את דף המשימות שלך.
4. לחץ על כפתור 📤 לומיו הפיני — המשימות תישמרנה בלומיו.

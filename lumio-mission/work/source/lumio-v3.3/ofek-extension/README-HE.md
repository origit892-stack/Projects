# Lumio MOE Sync — תוסף דפדפן (סנכרון אוטומטי ממשו״ב / אופק / פטל)

כל המערכות האלה (משו״ב, אופק/מטח, פטל) נכנסות דרך **הזדהות משרד החינוך**
(`lgn.edu.gov.il`). אין להן API ציבורי, וללומיו **אסור להחזיק את הסיסמה שלך**.
הפתרון: תוסף דפדפן קטן שרץ **על הדף שלך, עם הסשן הקיים שלך במשרד החינוך** —
הוא מציץ ב־JSON שהדף עצמו מקבל מהמערכת, ומסנכרן אותו ללומיו **אוטומטית**,
בלי לחיצות ובלי שמירת סיסמאות.

> זה בדיוק המודל שביקשת: אתה מתחבר דרך משרד החינוך, ולומיו "שואב" את
> המידע אוטומטית. התוסף הוא הצנצנת — הוא נשאר בדפדפן, רואה את ההתחברות
> הקיימת שלך, ושולח ללומיו רק את הנתונים (משימות / ציונים / מערכת שעות).

## מה נסונכר (אוטומטי, בלי לחיצות)
- **משו״ב** (`web.mashov.info`): משימות, ציונים, מערכת שעות.
- **אופק / מטח** (`*.cet.ac.il`, `*.matan.co.il`): משימות.
- **פטל**: משימות.

כל פעם שפותחים את המערכת, התוסף סופג אוטומטית (דבוב של 3 שניות + שליחה).
תצוגה קטנה בפינה השמאלית-תחתונה מראה: מחובר / מסנכרן / ✓ סונכרן.

## התקנה (פעם אחת, ~2 דקות)
1. Chrome/Edge → `chrome://extensions` (או `edge://extensions`).
2. **מצב פיתוח** (Developer mode) → **Load unpacked** → בחר את התיקייה `ofek-extension`.
3. פתח את **הגדרות התוסף**:
   - בלומיו, בכל מערכת שאתה מחבר, לחץ **מפתח סנכרון** והעתק.
   - הדבק כאן את המפתח/מפתחות (משו״ב, אופק, פטל — לפי מה שאתה מחבר).
   - שמור. ה־"✓ המפתח מזוהה" מאשר שזה עובד.
4. זהו. התחבר למערכת שלך כרגיל — מהרגע הזה כל פתיחה מסנכרנת אוטומטית.

## איך זה עובד (ובמה אמין)
- **מסלול ראשי (מדויק)**: `capture.js` רץ בעולם הדף (MAIN) ומציץ בתגובות ה־JSON
  של fetch/XHR; `map.js` ממפה לטורים של לומיו; `content.js` (עולם מבודד) שולח
  לאנדינג. הגשר ביניהם = CustomEvent על ה־DOM (תיקון של גרסה קודמת שניסתה
  לקרוא `window` מ־עולם אחר — לא עבד).
- **עקבי**: כל שליחה = upsert לפי מפתח יציב (`external_id`) — פתיחות חוזרות
  לא מייצרות כפילויות.
- **הגישה**: הנתונים נכנסים ללומיו עם סימון **סנכרון מקומי / דרך האתר** —
  לא "API רשמי" (שאין). מצב החיבור בלומיו משתנה רק אחרי שהנתונים באמת נקלטו.

## אבטחה (חשוב)
- **אין שמירת סיסמה.** התוסף לא קורא, לא שומר ולא שולח שום סיסמה/הזדהות.
  הוא עובד רק עם ההתחברות הקיימת שלך בדפדפן (עוגיות/CSRF של המערכת).
- המפתחות נשמרים ב־`chrome.storage.local` (מחשב זה בלבד). מחיקתם, או
  ניתוק המערכת בלומיו, עוצרים את השליחה. מפתח = קוד כניסה, ניתן לסובב.
- היעדים מוגבלים: התוסף מופעל רק על `web.mashov.info`, `*.cet.ac.il`,
  `*.matan.co.il`; שליחה רק לכתובת Supabase של לומיו.
- המפתח מזוהה בשרת עם המשתמש היחיד שאליו מותר לכתוב — אף משלח לא יכול
  לכתוב לחשבון אחר.

## אם זה לא עובד
- וודא שהתוסף פעיל בדף (אייקון תוספים → פינץ' על דף המערכת).
- פתח את המערכת ונתן להטען (התוסף מציץ ב־JSON שנטען).
- אם המבנה ה־JSON של המערכת השתנה: צלם את השגיאה — יותאם המזין.

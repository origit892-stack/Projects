# Lumio × אופק — תוסף דפדפן (לכל מחשב)

אופק (מטח) מתחבר רק דרך **הזדהות משרד החינוך** — אין לו API ציבורי, ואסור
ללומיו להחזיק את הסיסמה שלך. הפתרון: תוסף דפדפן קטן שרץ **על הדף שלך, עם
הסשן שלך** — הוא סופג את המשימות שהדף עצמו מקבל (JSON) ושולח אותן ללומיו
בכפתור אחד. **לא נשמרת אף סיסמה** — רק מפתח הסנכרון (קוד כניסה, ניתן לסובב).

## התקנה (פעם אחת, ~2 דקות)
1. בדפדפן Chrome/Edge: `chrome://extensions` (או `edge://extensions`).
2. בלון ימין: **מצב פיתוח** (Developer mode) → **טעינת תוסף לא־חתום**
   (Load unpacked) → בחר את התיקייה `ofek-extension` מזו.
3. פתח את **הגדרות התוסף** (אייקון הגדרות ברשימת התוספים):
   הקלד את **מפתח הסנכרון** (מלומיו, כרטיס אופק → מפתח סנכרון) ולחץ שמירה.
   ה"✓ המפתח מוכר" מאשר שזה עובד.
4. התחבר לאופק כרגיל, פתח את **דף המשימות**, ולחץ על כפתור **📤 לומיו**
   הפיני (שפה-שמאלית למטה).

## איך זה עובד (ובמה אמין)
- **מסלול עיקרי**: התוסף מציץ בתגובות ה־JSON שהדף שלך מקבל (fetch/XHR)
  ומזהה רשימות משימות לפי המבנה — זה המסלול המדויק.
- **מסלול גיבוי**: אם לא נתפס JSON (עמוד מתוקתק), הוא קורא את הטקסט הנראה
  ברשימה (כותרת + תאריך) — פחות מדויק, עדיף על כלום.
- התוצאה מופיעה בלומיו תחת אופק עם סימון **"סנכרון מקומי"** — לא API רשמי.
- כל שליחה = עדכון (upsert) לפי מפתח יציב — לחיצות חוזרות לא מייצרות כפילויות.

## אבטחה
- הסיסמה/הזיהוי שלך נשארים בדפדפן. התוסף לא קורא אותם, לא שומר אותם,
  ולא שולח אותם לשום מקום.
- המפתח נשמר ב־`chrome.storage.local` (מחשב זה בלבד). מחיקתו, או ניתוק
  אופק בלומיו, עוצרים את השליחה.
- היעדים: דפי אופק בלבד (התוסף מופעל רק על `*.cet.ac.il` / `*.matan.co.il`),
  ושליחה רק לכתובת ה־Supabase של לומיו.

## אם זה לא עובד
- ודא שהתוסף מופיע כפעיל בדף אופק (אייקון תוספים → פינץ').
- פתח את דף המשימות **לפני** הלחיצה.
- אם ה-JSON משתנה: שלח צילום מסך של השגיאה — יותאם המזהה.

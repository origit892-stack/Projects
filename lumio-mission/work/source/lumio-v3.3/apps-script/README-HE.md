# סנכרון יומי אוטומטי של Classroom — הוראות לתלמיד (Hebrew)

לומיו 4.0 מאפשר סנכרון יומי **חינם** של Google Classroom, גם כשהמחשב כבוי. הסנכרון
רץ בפרויקט Apps Script **שלהך** — בחשבון Google שלך, על תשתית של גוגל. ללומיו אין
אף פעם סיסמה שלך, אין OAuth client, אין GCP ואין refresh token.

## מה הסקריפט קורא ומה הוא כותב
- **קורא (בלבד):** הקורסים שלך, המטלות/אוצר מילים/חומרי קורס, וההגשות שלך
  (סטטוס + ציון שניתן). זהו בדיוק היקף הרשאות ה־Classroom הרגילות שלך.
- **כותב (בלבד):** לחשבון לומיו שלך, דרך מפתח הסנכרון שאתה יוצר בלומיו
  (חשבון → הגדרות פרטיות → "צור מפתח לסנכרון יומי").

## 5 צעדים — להפעלה חד-פעמית
1. פתח https://script.google.com (בהתחברות לחשבון Google שלך) → **פרויקט חדש**.
2. מחק את הטקסט שנמצא בעורך, והדבק את כל תוכן הקובץ `classroom-sync.gs` מתיקיית `apps-script` בלומיו.
3. בלומיו: חשבון → הגדרות פרטיות → "צור מפתח לסנכרון יומי". העתק את שני הערכים:
   - כתובת ה־Edge Function שלך: `https://<הפרויקט>.functions.supabase.co/apps-script-ingest`
   - מפתח הסנכרון (32 תווים).
   הדבק את שני הערכים בראש הסקריפט — השתמש בשורת `LUMIO_FN_URL` ושורת `LUMIO_SYNC_KEY`.
4. באפליקציית Apps Script: בחר בפונקציה **setup** ולחץ **Run**. גוגל תבקש אישור
   הרשאות (Classroom) — אשר. זה יוצר טריגר יומי אחד בשעה 06:00 (שעון ישראל).
5. סיום. התראתה של תאימות: כדי שה־Edge Function יעבוד, מנהל לומיו צריך כבר לפריסם
   את `supabase-functions/apps-script-ingest` (ראה `supabase-functions/README-HE.md`).

## מכסות (נבדקו 2026-11-12, ללא עלות)
- עד 20 טריגרים לפרויקט (אנחנו משתמשים ב־1).
- עד 90 דקות זמן ריצה ביום.
- עד 20,000 קריאות URLFetch ביום.
ריצת sync רגילה לוקחת שניות בודדות.

## איך מבינים שזה עובד
ב־Lumio: חיבורים → Google Classroom → "סנכרון הצליח — [זמן]". ב־Apps Script:
Executions יציג ריצה יומית, וב־Logs: `sync ok, items=N`. אם המפתח או הכתובת
לא תקינים יופיע `LUMIO_BINDING_INVALID`.

## איך מבטלים
- **בלומיו:** חשבון → הגדרות פרטיות → "בטל סנכרון יומי" (מפסיק את המפתח מיד),
  ו/או "נתק" מתחת לכרטיס Classroom.
- **בגוגל:** script.google.com → הפרויקט שלך → מחק פרויקט. (או סמן את הטריגר
  ב־Triggers ומחק אותו.)

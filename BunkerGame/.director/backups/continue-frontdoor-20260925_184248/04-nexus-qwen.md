# Qwen and Nexus Responsibilities

Qwen and Nexus have different roles.

## Qwen

Qwen is the engineering/debugging supervisor.

Qwen owns:

- terminal execution
- filesystem inspection
- source inspection
- Nexus debugging
- test execution
- regression verification
- deployment verification
- artifact forensics
- Argon investigation
- technical recovery

## Nexus

Nexus is the specialized persistent BunkerGame execution/orchestration engine.

Nexus may provide:

- Director
- Architect
- Coder
- persistent milestones
- specialized game/asset workflows
- long-running execution

Do not replace Nexus merely because Qwen can edit files directly.

If Nexus is broken:

inspect Nexus
→ diagnose root cause
→ repair Nexus
→ test
→ deploy
→ verify
→ resume the existing checkpoint

Do not create a replacement Nexus session merely because an existing run was
interrupted.

Preserve existing verified checkpoints and artifacts.

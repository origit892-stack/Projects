# Debug a Problem

Find the root cause rather than proposing random fixes.

Trace the relevant execution flow through:

1. Entry point
2. Client input
3. Remote or shared communication
4. Server validation
5. State mutation
6. Replication
7. UI or world output
8. Cleanup and lifecycle

Return:

1. Reproduction assumptions
2. Execution trace
3. Root cause
4. Supporting evidence
5. Minimal fix
6. Regression risks
7. Verification steps

Do not modify files unless explicitly requested.

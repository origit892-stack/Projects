# Review Code

Review the requested code as a senior Roblox engineer.

Inspect the implementation and its direct dependencies.

Prioritize:

1. Runtime errors
2. Incorrect behavior
3. Exploit vulnerabilities
4. Data-loss risks
5. Client-server authority
6. Replication and lifecycle
7. Performance and memory
8. Maintainability

For every finding include:

- Severity
- Exact file path
- Evidence
- Impact
- Specific fix

Do not modify files unless explicitly requested.

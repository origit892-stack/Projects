# Greenfield Bunker Staging Artifact

`GreenfieldBunker.model.json` is the deterministic staging snapshot generated by
`tools/builders/generate_greenfield_bunker.py --mode staging`.

It is deliberately outside the Rojo-mapped `src/Workspace` tree after the
source-controlled active cutover, so the isolated review facility cannot become
a second live entrance target, prompt set, light grid, or performance cost.
The builder remains the canonical source and can reproduce this artifact.

# BunkerGame AI Knowledge Library

This directory is the persistent technical knowledge base for BunkerGame.

Source code and `default.project.json` remain the primary sources of truth.

## Documents

- `PROJECT.md` — product and gameplay overview
- `ARCHITECTURE.md` — system boundaries and runtime architecture
- `SYSTEMS.md` — index of known game systems
- `FARMING.md` — farming system
- `INVENTORY.md` — player inventory and resource state
- `ECONOMY.md` — credits, costs, rewards, and progression
- `ZOMBIES.md` — zombie models, spawning, and behavior
- `BUILDING.md` — bunker, upgrades, workbenches, and construction
- `POWER.md` — batteries, processors, lights, and power state
- `NETWORKING.md` — remotes and communication contracts
- `MODULES.md` — ModuleScripts and dependency relationships
- `TESTING.md` — validation and regression plans
- `DECISIONS.md` — architectural decision records
- `TODO.md` — evidence-based technical work
- `CHANGELOG-AI.md` — AI-assisted documentation changes

## Evidence states

Use:

- Confirmed
- Unknown
- Hypothesis
- Unverified binary content

Do not promote hypotheses to confirmed facts without inspected evidence.

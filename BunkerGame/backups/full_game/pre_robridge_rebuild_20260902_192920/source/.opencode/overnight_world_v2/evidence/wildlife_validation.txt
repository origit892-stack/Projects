HOW MOVEMENT WORKS
------------------
Tick rate: 3-second interval via task.delay loop (NOT RunService.Heartbeat)
Deer movement: TweenService CFrame tween between deterministic waypoints
  - Speed: 5 studs/sec (slow walk)
  - Waypoints: 10 fixed positions across west/east forest zones
  - Each deer cycles through its assigned waypoints deterministically
  - No per-frame AI computation
Bird movement: TweenService CFrame linear traversal
  - Speed: 18 studs/sec
  - Period: 45 seconds between crossings
  - Direction alternates each crossing
  - Y altitude: 75 (high overhead, distant)

DETERMINISTIC COMPLIANCE
------------------------
- All waypoint positions are hardcoded constants (no math.random)
- RuntimeRandomness attribute on GameWorld: false (compliant)
- Deer start indices: fixed array { 1, 3, 5, 7, 9 }
- Bird paths: fixed start/end coordinates
- Tween timing: deterministic distance/speed calculation

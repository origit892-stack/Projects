   -> invoke bunker-builder through Task from Muse.
   -> do not launch it as primary and silently fall back to another model.

   -> NEVER use /tmp.
   -> retry with project-local evidence/build path.

7. BLOXFORGE DIRECT MCP HAS NO REQUEST ID
   -> record NONE_DIRECT_MCP.
   -> do not invent bridge request IDs.

   -> do not treat historical pending queue requests as production blockers.
   -> MiMo has direct BloxForge MCP access.

9. ROJO PATH
   -> use $HOME/.aftman/bin/rojo.

10. ROJO VALIDATION OUTPUT
   -> write inside project only.

11. PLAY LEFT RUNNING
   -> stop immediately and verify Edit before further source work.

12. SCRIPT ERROR
   -> inspect console/stack;
   -> locate canonical filesystem source;
   -> fix source;
   -> validate;
   -> sync;
   -> rerun focused QA.

13. CREATURE AI EXPENSIVE
   -> reduce update frequency;
   -> use state scheduling;
   -> distance/sleep logic;
   -> avoid per-frame server loops for every animal.

14. NAVIGATION BLOCKED
   -> fix placement/terrain/geometry, not by disabling all collision globally.

15. ASSET LOOKS BAD
   -> Muse REJECTS;
   -> do not register;
   -> revise/regenerate;
   -> re-QA.

16. ASSET TECHNICALLY BAD
   -> BloxForge fixes engineering problem where possible.
   -> regenerate only if geometry itself is fundamentally unsuitable.

17. ROJO SOURCE/LIVE DRIFT
   -> determine intended canonical source.
   -> never silently overwrite unknown important work.

18. MCP DISCONNECT
   -> retry/recover;
   -> freshly inspect connection;
   -> do not fabricate successful tool calls.

# Implement a Feature

Implement the requested Roblox feature using the existing architecture.

Before editing:

1. Inspect the relevant source files.
2. Inspect direct dependencies.
3. Read the relevant Rojo mapping.
4. Identify client, server, and shared responsibilities.
5. Identify existing remotes and public interfaces.
6. Present a concise implementation plan.

During implementation:

- Make the smallest coherent change.
- Reuse existing systems.
- Preserve unrelated behavior.
- Keep server authority for trusted game state.
- Validate client requests.
- Avoid unnecessary abstractions.

After implementation:

- Review changed files.
- Check syntax.
- Check networking and security.
- Check lifecycle and replication.
- Summarize changed files and remaining risks.

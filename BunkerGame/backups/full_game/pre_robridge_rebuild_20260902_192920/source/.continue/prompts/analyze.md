# Analyze a System

Inspect the requested system using the project rules.

Before answering:

1. Read `default.project.json`.
2. Read every relevant Lua and Luau file.
3. Follow direct require relationships.
4. Inspect both sides of client-server communication.
5. Inspect large files in successive sections.

Return:

1. Scope inspected
2. Confirmed behavior
3. File and module relationships
4. State ownership
5. Networking contracts
6. Runtime and lifecycle risks
7. Security risks
8. Performance risks
9. Unknowns
10. Hypotheses
11. Recommended next steps

Cite exact file paths.

Do not modify files.

# BunkerGame — UI Bible

## Direction

Premium survival-horror UI.

Industrial.
Minimal.
Readable.
Atmospheric.

UI appears when information is useful.

## HUD Philosophy

Persistent information should be minimal.

### Top

Potential information:
- Day
- time
- night countdown
- wave state
- important resources

### Center

- minimal crosshair
- contextual interaction

### Bottom

- health/status
- custom hotbar

## Hotbar

Initial slots:
1. Rifle
2. Pickaxe
3. Torch
4+. Future equipment

## Contextual UI

- processing progress is hidden at 0%
- farming information appears while farming
- shop UI appears while trading
- warnings appear temporarily
- notifications fade out

## Horror Presentation

Use:
- short flicker
- restrained glitch
- warning pulse
- mechanical transitions
- subtle audio

Avoid:
- constant glitch
- constant shake
- excessive screen clutter

## Input

Support:
- mouse/keyboard
- touch
- gamepad

## Legacy Migration

Legacy UI is removed only after equivalent functionality exists in the replacement UI.
